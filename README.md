# Portfólio — Maria Régia Batista Magalhães de Lima

Site pessoal estático para GitHub Pages.

## Publicação

1. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório `lmmaria.github.io`.
2. Acesse **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**; escolha a branch principal (`main` ou `principal`, conforme exibida) e a pasta `/ (root)`; clique em **Save**.
4. Após a publicação, visite https://lmmaria.github.io/.

As imagens de projetos são representações gráficas provisórias. Substitua-as por fotos reais quando desejar.
